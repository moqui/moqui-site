Why Moqui

Less code, more of the business

  • Low code: efficient tools and existing artifacts mean less to build, maintain, and support. One large project replaced over a million lines of code with less than 100k.
  • REST APIs to build and to consume, full-text search and analytics, managed messaging, and runtime authorization with automatic query filtering.
  • Multi-instance provisioning for SaaS (Docker and MySQL included; other hosts via service interfaces).
  • Deploy as a standalone executable or a WAR, on VMs, containers, on-prem, or private cloud.

License

Public domain, on purpose

Moqui is free and open source software, released in the public domain. To make that hold where public domain is not recognized, the projects use the Creative Commons CC0 1.0 Universal Public Domain Dedication.

Because CC0 does not cover patents, the ecosystem also uses a Grant of Patent License adapted from Apache License 2.0. See LICENSE and AUTHORS.

How the project is run

Moderated, not a free-for-all

A small group of moderators review every change to the official repositories. Users, sponsors, and contributors get a code base that stays aligned with the design instead of decaying from convenience commits.

The normal way to get a change in is to work with a moderator — implement it together, or review a patch, revise, and commit. See the Community documentation for collaboration infrastructure.
