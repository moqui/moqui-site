Marble ERP

General purpose ERP for goods and services

code · releases · docs · issues

  • General enterprise management and automation: 277 screens and 894 forms
  • Comprehensive, production proven, and usable out of the box
  • Retail and wholesale: goods production, warehousing, sales, and shipment (like POPC ERP)
  • Services and internal work: requests, projects, tasks, events/calendars (like HiveMind)
  • Built on Moqui Framework and Runtime, Mantle UDM and USL, and Simple Screens
  • Mantle USL includes a REST API with 422 endpoints; the framework makes additional endpoints easy to add

HiveMind

Project management and service ERP

code · releases · issues

  • Project management app with 36 screens and 74 forms
  • Admin app with 129 screens and 364 forms
  • Projects with milestones and hierarchical tasks
  • Powerful task search, easy task summary and updates
  • Wiki with attachments, history, project and task associations
  • Client requests associated with tasks
  • Record task time and project expenses
  • Project budgets by time and cost, tracked against progress
  • Client and worker invoices based on project time and expenses
  • Accounts payable and receivable, general ledger, financial reports, invoice and check PDFs
  • Built on Moqui Framework and Runtime, Mantle UDM and USL, and Simple Screens

POP REST Store

eCommerce application and REST API

code · releases · issues

  • Server-rendered product browsing and searching screens
  • Vue JS single-page application for checkout and customer profile/portal
  • Modern look and feel, usable as-is and meant to be customized and extended
  • Same platform and database as the ERP, so data stays in sync
  • eCommerce REST API usable from custom sites on other platforms, from Angular to WordPress

POP Commerce

Retail and wholesale ERP and eCommerce

code · releases · docs · issues

  • ERP (Admin) app with 251 screens and 832 forms
  • Example eCommerce application with 18 screens
  • Flexible product model (content, classes, categories, features, IDs, dimensions, associations)
  • Product, customer, content, and related faceted search
  • Suppliers, purchasing, receiving, inventory and warehouse management, reservations
  • Customers, requests, sales, pick/pack, shipping
  • AP, AR, general ledger, financial reports, budgets, sales and financial analytics
  • PDFs for invoices, orders, checks, picklists, pack sheets and inserts
