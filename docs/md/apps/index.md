# Moqui Applications

This space contains documentation for the open source applications in the Moqui Ecosystem.

The only user guide here is for **Marble ERP**. Other applications exist in the current Moqui tree but do not have user guides in this space.

* **[Marble ERP](/docs/apps/Marble+ERP+User+Guide)**: a comprehensive ERP for businesses that produce goods and services and sell to individuals (B2C) and organizations (B2B). It mounts SimpleScreens for quote to cash, procure to pay, accounting, warehouse, light manufacturing, projects, and related operations. Default UI: `/qapps/marble` (demo: `https://demo.moqui.org/qapps/marble`).
* **POP Commerce**: retail and wholesale ERP plus eCommerce. The admin app is POPC ERP (`/qapps/PopcAdmin`). The storefront is **PopRestStore** (`/store`). No user guide here.
* **HiveMind**: project management and services ERP (`/qapps/hm`). No user guide here.
