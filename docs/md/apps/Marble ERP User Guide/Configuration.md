# Configuration

Before we can begin using POP Commerce, it needs to be setup and configured. The POP Commerce demo can also provide examples of the type of data that you will need. Let's take a look at the main steps needed for configuration. 

1. First of all we need to setup our main company and internal users who will be using POP Commerce (e.g customer service, warehouse, accounting etc)
1. Then we need to setup the company chart of accounts 
1. Next we need to setup the products that we want to buy or sell
1. After that we can setup locations where we store or sell our products
1. Finally we can setup our customers and suppliers
