# Configuration

Before we can begin using Marble ERP, it needs to be set up and configured. The Marble ERP demo can also provide examples of the type of data that you will need. Let's take a look at the main steps needed for configuration.

1. First of all we need to set up our main company and internal users who will be using Marble ERP (e.g. customer service, warehouse, accounting, etc.)
1. Then we need to set up the company chart of accounts
1. Next we need to set up the products that we want to buy or sell
1. After that we can set up locations where we store or sell our products
1. Finally we can set up our customers and suppliers
