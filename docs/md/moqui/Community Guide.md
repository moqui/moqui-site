# Community Guide

[TOC levels=2-3]

## Where the Community Lives

The Moqui community collaborates in a few public places:

- **Documentation**: this site. Source is markdown in the [moqui-site](https://github.com/moqui/moqui-site) repository (`docs/md/`).
- **Discussion**: the [Moqui Forum](https://forum.moqui.org) (Discourse) is the primary place to ask questions and talk with other users and contributors.
- **Code, issues, and pull requests**: [GitHub](https://github.com/moqui). File issues and pull requests on the repository that contains the relevant code.
- **Demo**: [demo.moqui.org](https://demo.moqui.org) (login required; the John Doe test login is on that login screen).

moqui.org is a static documentation and directory site. It does not host a wiki, issue tracker, login, or HiveMind. HiveMind is an application you can run yourself or try on the demo.

See the [Contributor Guide](/docs/moqui/Contributor+Guide) and the [Issue and Pull Request Guide](/docs/moqui/Issue+and+Pull+Request+Guide) for how to contribute.

## Documentation

Current documentation for the Moqui Ecosystem is on this site, including the [Framework](/docs/framework), [Mantle](/docs/mantle), and [Applications](/docs/apps) spaces.

The 2014 book *Making Apps with Moqui* is outdated. Use the framework documentation under `/docs/framework` instead.

To help with documentation, open a GitHub pull request against [moqui-site](https://github.com/moqui/moqui-site). If you are new to Moqui, start by participating on the Forum so others know who you are.

## Questions and Support

Peer support is available so we can help each other. People who might respond are volunteers, people just like you, and Moqui is a community-backed (not company-backed) open source project. If you need more timely or consistent support, or support that is more than a question on a specific topic, consider hiring a [Service Provider](/service.html).

**[Moqui Forum](https://forum.moqui.org)** (this is the primary community collaboration resource)

**[Stack Overflow](https://stackoverflow.com/questions/tagged/moqui)** (large audience, meant for questions)

If you are not sure whether you have a question or want to discuss something, use the Forum.

## Issues and Other Requests

File issues and other requests as GitHub issues on the repository that contains the relevant code. For the framework that is typically [moqui-framework issues](https://github.com/moqui/moqui-framework/issues). Browse all repositories at [github.com/moqui](https://github.com/moqui). Documentation issues and pull requests go to [moqui-site](https://github.com/moqui/moqui-site).

Please read and follow the guidelines in the [Issue and Pull Request Guide](/docs/moqui/Issue+and+Pull+Request+Guide).

Do not file issues on moqui.org. It no longer hosts HiveMind or an issue tracker.

### Security Issues

To report security issues that should not be disclosed publicly before they are fixed, please use the private **[moqui-board@googlegroups.com](mailto:moqui-board@googlegroups.com)** mailing list. Anyone can send messages to it, but only members of the group can read the messages.

## Source Code

All source code for Moqui Ecosystem projects is hosted on [GitHub](https://github.com/moqui).

Code contributions must be submitted as pull requests on GitHub. See the [Contributor Guide](/docs/moqui/Contributor+Guide) and the [Issue and Pull Request Guide](/docs/moqui/Issue+and+Pull+Request+Guide) for more detail.

## Project Planning and Collaboration

Planning and collaboration happen through GitHub issues and pull requests, and through discussion on the Forum.

HiveMind is a project management application you can run locally or try on the public demo at [demo.moqui.org/qapps/hm](https://demo.moqui.org/qapps/hm) (login required). Marble ERP is on the same demo at `/qapps/marble`. HiveMind is not hosted on moqui.org and is not the community control plane.
