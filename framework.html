What is Moqui Framework?

Moqui Framework is a seamlessly integrated, enterprise-ready framework for building enterprise automation applications based on Java. It includes tools for database interaction (relational, graph, document), logic in local and web services, web and other UI with screens and forms, security, file/resource access, scripts, templates, localization, caching, logging, searching, business rules, workflow, multi-instance deployments, and integration.

It is designed so you work on what you care about and let the framework take care of the rest: efficient tools and consolidated files for small apps; a true 3-tier architecture and service-oriented design for very large applications; and you control your data, with Mantle UDM giving you a place to put what you need.

  • Built-in support for advanced tools such as Jackrabbit (content), Camel (integration), ElasticSearch (search), Drools (rules), and jBPM (workflow)
  • Clustering with Hazelcast (other similar tools are pluggable) for database cache invalidation, web session replication, background service executor, user notification, and JCache
  • More flexible and secure than hosted PAAS frameworks, and easy to host on-premise or in the cloud
  • A next-generation design based on over a decade of innovation and experience with Apache OFBiz

No code generation. Dynamic runtime functionality keeps development artifacts small and easy to maintain, not just easy to create. True 3-tier architecture: a strongly defined logic layer around service-oriented principles, so a service library for internal use can be exposed externally as needed.

The next layer up is Mantle: a Universal Data Model, Universal Service Library, and screens/forms on top of that. For a fuller list see Framework Features.

Why this tool set

The design criteria were strong best practices (a place for everything), a small tool set to reduce switching costs, and efficient artifacts: simple, reusable by design, easy to read as well as write, minimally error prone, and small. As teams and projects get larger, consistency beats a pile of familiar-but-different frameworks.

Moqui is based on a decade of experience designing Apache OFBiz tools against real-world business application requirements, and using those tools to build systems that have been reused for thousands of custom systems. As OFBiz grew it became harder to make dramatic framework changes. Moqui is those improvements — convention over configuration, less redundancy, more consistency — in a fresh design.
